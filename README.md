# Myntra Landing Page Clone

A simple clone of the Myntra home/landing page built using **HTML and CSS**.

## 🛠️ Technologies
- HTML5
- CSS3

## 📌 About
This project was created to practice CSS layouts, positioning, spacing, styling, and page structure by recreating the Myntra landing page.

## 🚀 Live Preview

[**View Live Project →**](https://aradhya.lusa.co.in/CSS-Project-Myntra-Clone)

> **Note:** This project is not responsive and was created for learning purposes.

## ▶️ Run Locally

Open `index.html` in your browser, or clone the repository:

```bash
git clone https://github.com/Aradhya89/CSS-Project-Myntra-Clone.git
cd CSS-Project-Myntra-Clone
```
